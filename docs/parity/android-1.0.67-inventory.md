**Status key:** **Gap** means a mismatch is visible in source; **Partial** means an entry and part of the behavior exist, but a named part differs; **Present** means both paths have production wiring, not that the paths passed runtime tests; **Verify** means the source is insufficient to declare the outcome; **Platform** means use and test the native outcome or document what is not supported; **Parallel** means no duplicate work here. Priorities apply to follow-up, not proof of a runtime incident. P1 affects access to data, data correctness, or an entire released workflow. P2 is a narrower behavior or interaction gap.

## Highest-priority follow-up

1. **Protect exported data and calendar availability (E01, E05).** Keep timetable and course payload keyed to the same ID and fail closed if a non-current load fails. The direct calendar flow also needs the correct modern EventKit authorization path; a purpose string does not request permission. Files and ICS sharing are separate paths and do not test Calendar integration.
2. **Deliver date-specific periods as data, not just as a utility (T05, T06, J05).** Android captures the combination, persists it in the period table and a full archive, and uses the occurrence date in several consumers. In iOS the capture bridge explicitly declines the combination, the database and backup DTO have no field, and the resolver is uncalled outside its own file and tests. This can block a complete Qingdao import and can leave otherwise correct timetable selections showing or notifying at the base time. Do not use #55 as a proxy for fixing the data path.
3. **Split academic update eligibility from portable source metadata (J02–J04).** iOS has an update icon and the review flow, but the icon is unconditional and opens the general school picker. Android uses the verified source on the specific target timetable to show the action and launch the exact school/protocol/entry. Restoring or copying identity must not grant eligibility.
4. **Complete the portability paths (E08, I04, I05).** Local Files backup is not manual WebDAV backup. WakeUP shares lose named fields on iOS despite successful decoding, and confirmed imports can accept chronologically overlapping period rows. These are independently testable source differences.
5. **Restore the compact grid quick-add workflow (V02).** The existing iOS meeting editor has course color controls. It is the entry mode, the same-draft transition to More, and the picker behavior there that need to be addressed, not the primary theme setting.
