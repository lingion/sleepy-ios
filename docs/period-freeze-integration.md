# 删除作息表的冻结语义

- 对照上游 `PeriodTableDeletion.kt`，显式用户删除在同一 GRDB 事务内读取绑定课表，水合当前共享作息，再清除绑定和旧绑定前快照，最后删除源作息。
- 课程行不重排，绑定表保留删除时实际使用的时间、节次数和智慧节次配置。
- `deletePeriodTable(_:onlyIfUnbound:)` 的旧调用默认保持未绑定守卫；用户确认路径显式传 `false`，放弃新建草稿路径仍走守卫，避免删除已被其它课表采用的作息。
- 撤销快照在事务成功后入栈，删除失败的数据库回滚不消费历史。删除、恢复和重做仍触发既有数据通知。
- 新增 `PeriodTableFreezeDeletionTests` 覆盖两张绑定表冻结与撤销/重做、草稿守卫、删除故障事务回滚。
- 确认弹窗说明保留当前作息，失败文案不再误称被引用禁止删除。
