# Sleepy iOS 真机验收清单（2026-11-07 修订）

本清单替代旧版中“所有编译已通过、后台自动切课和自动结束”等未经验证的承诺。本轮只完成工程生成和静态检查；未运行构建、单元测试、UI测试或模拟器。当前工程位于 `.claude/worktrees/ios-audit-repair/Sleepy.xcodeproj`，不是主 checkout 的工程。

## 提醒与实况活动

- [ ] 提醒总开关打开后，课前提醒内可选择“实况活动（灵动岛）”；开启后横幅关闭，关闭后回到横幅。
- [ ] 系统禁止实况活动时显示设置引导，通知授权不被说成实况活动授权。
- [ ] 只为开启提醒的课表显示课程；关闭提醒总开关、课前提醒或表提醒后，回到前台不再留有活动。
- [ ] 提前10分钟时开始显示；提前更久不创建空白卡片；课间正确指向下一门课。
- [ ] 课程名称、教室、结束时间变更后，前台活动同步更新，即使开始时间未变。
- [ ] 前台跨上课/下课边界时正确切换/结束；锁屏、紧凑、展开和最小形态均有可读内容。
- [ ] 在后台或杀掉App后：已有系统倒计时可继续，但不要求自动切课/自动消失；重新打开后校准。iOS16.2+过期状态有明确提示。
- [ ] iOS15.6/16.0不显示实况选项，不崩溃；无灵动岛设备验收锁屏卡片。

## 小组件

- [ ] 画廊点卡片能开引导，标题 `widget_guide_title` 与关闭按钮 `topbar_close` 可分别识别。
- [ ] 复制内容为应用名 `Sleepy`，不是组件标题；按“编辑 → 添加小组件”（旧系统为＋）搜索应用、选择组件尺寸、添加并完成。
- [ ] 关闭引导后回到画廊；五种语言均不出现原始资源键。

## 课表与手势

- [ ] 双指上下拉开/缩合时行高变化，确认✓后重启仍保持相同的卡片高度。旧设置已明确关闭时不自动覆盖。
- [ ] 手势取消、切表、离开页面后单指滚动可用；原本禁滚动的宿主不会被手势清理误开启。
- [ ] 横屏进入双栏，回竖屏退出；iPhone/iPad和分屏分别验收。
- [ ] 常规两节课跨过其他课程产生的占位行时，高度仍覆盖两个真实节次。
- [ ] 午休前只有一分钟的自定义课有正高度，不消失或产生非法frame。
- [ ] 同周拖动一节课，原位置不再显示该周实例；跨周移动保留其它周的课。此真机报告尚未复现，不能标为通过；CI中跳过的拖动测试不算验证。

## 导入、导出、同步

- [ ] 替换16周课表为24周课表，周数、课程、日期与作息一起提交。
- [ ] 模拟导入数据库失败或目标被删除：保留预览，显示失败，不显示成功；原数据、undo/redo不改变。
- [ ] 追加导入时作息扩展和课程插入一并成功或回滚。
- [ ] 修改绑定作息表后，JSON、ICS、分享文本导出的时间与界面一致，分享文本包含作息信息。
- [ ] 手表收到一次快照后同步次数能稳定下来，不因回执持续发送新快照。
- [ ] 删除某张课表的最后一条调休后，手表收到新快照也清空该映射；离线冷启动读取收到的快照而不是自己发送的回执。
