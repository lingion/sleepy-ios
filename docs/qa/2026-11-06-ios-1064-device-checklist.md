## ② 双指捏放行高（本轮核心修复）

> **背景**：功能 1.0.61 已移植但默认关闭，且你实测「开了开关仍捏不动」。本轮把 pinch 识别器从 `.background` 匿名宿主改挂到课表真实滚动视图（UIScrollView），并让默认值改为**开**（实验室开关保留可关）。

| # | 验收点 | 通过标准 |
|---|--------|----------|
| 2.1 | 默认值 | 升级后首次进入课表即可捏合（无需先去设置开开关）；「通用设置 → 实验室 → 双指捏放调整行高」应显示为开启 |
| 2.2 | 捏合触发 | 在课表（周视图/日视图卡片面）用两指上下捏放 → 行高实时变化（不会没反应） |
| 2.3 | 提交 | 捏合后顶栏出现 ✓ 确认按钮；点 ✓ 后按钮消失 |
| 2.4 | 持久化 | 彻底杀掉 App 重启 → 行高保持在上次确认值；切表后再切回 → 回到该表确认值 |
| 2.5 | 关掉开关 | 设置里关掉实验室开关 → 回到课表捏合不再生效；再开 → 即时生效 |
| 2.6 | 与滚动共存 | 单指纵向滚动课表、横向翻周都正常（捏合不应把滚动吃掉）；捏合过程中页面不跟手乱滚 |

## ③ 应用内小组件添加引导（新）

> **背景**：iOS 无「应用内程序化把小组件放上桌面」的 API（已用本机 SDK 头文件实证），所以把原「点卡片 = 不支持」的死胡同，改成一页能照做的引导 + 复制组件名。

| # | 验收点 | 通过标准 |
|---|--------|----------|
| 3.1 | 入口 | 我的 → 小组件 → 管理 → 右上 ＋ → 画廊；点任意卡片 |
| 3.2 | 引导页 | 弹出「把小组件加到桌面」sheet：含该组件名 +「复制名称」按钮 + 组件预览图 + 4 步图文 |
| 3.3 | 复制 | 点「复制名称」→ 按钮短暂变「已复制」；剪贴板里是该组件在系统小组件库的真实名称（如「本周课表（网格）」） |
| 3.4 | 照做可行 | 按引导：长按桌面 → 左上 ➕ → 搜索框粘贴名字 → 找到该组件 → 拖上桌面成功 |
| 3.5 | 关闭 | 点 sheet 左上 ✕ 关闭，画廊页正常返回 |
| 3.6 | 管理页空态文案 | 没添加过小组件时空态提示不再说「不支持快捷添加」 |

## ④ 灵动岛 Live Activity（新）

> **平台上限（必须心里有数）**：纯本地无服务端 → 卡片只能在 App 活跃时创建/刷新；**App 完全退出后，新的卡片要等下次打开才出现**。无灵动岛机型（<iPhone 14 Pro）显示为锁屏实况条；iOS 16.1 以下完全不生效。

| # | 验收点 | 通过标准 |
|---|--------|----------|
| 4.1 | 开关入口 | 我的 → 提醒 → 课前提醒：除「横幅」外出现「课前方式」的实况/流体云选项；副标题是 iOS 灵动岛文案（不是小米/vivo 文案） |
| 4.2 | 权限 | 通知权限需已授权（实况活动沿用系统授权） |
| 4.3 | 开启后 | 选实况方式；App 保持在前台（或锁屏后再点亮）时，有课当天出现实况卡片：图标书本 + 剩余时间倒计时；长按展开 = 课程名 + 教室 + 下课倒计时 + 进度条 |
| 4.4 | 岛内三段 | compact：左书本、右倒计时；minimal：剩余分钟数；expanded：课程/教室/倒计时/进度 |
| 4.5 | 熄屏→锁屏 | 活动期间锁屏上也显示该课程实况；下课瞬间该卡自动结束消失 |
| 4.6 | 段刷新 | 相邻两节课（间隔 ≤60 分钟）属同一条卡，第一节课后自动过渡显示第二节；两节之间空闲 >1 小时的，第二段卡片需回一次前台才出现（上限，非缺陷） |
| 4.7 | 退出 App | 杀掉 App → 进行中的卡继续走到下课自动消失；**新的卡**不再出现，直到下次打开 App |
| 4.8 | 关掉方式 | 把课前方式切回「横幅」或关掉课前提醒 → 现有实况卡消失；桌面上不该残留 |
| 4.9 | 旧系统 | 用 iOS 16.0/15.6 设备装 → App 正常、不崩，提醒页不显示实况选项 |
| 4.10 | 音频/专注模式 | Live Activity 不应产生横幅弹窗或打断音频（它是静默常驻卡） |
